# Delcon — JEE Mains Chapter-Wise & Subject-Wise PYQ Platform

A modern, high-performance web platform publishing **JEE Mains Previous Year Questions (PYQs)** organized chapter-wise and subject-wise (Physics, Chemistry, Mathematics). Built with clean, accessible semantic HTML5, modern CSS3, and lightweight vanilla JavaScript (ES6+).

---

## 🚀 How to Run & Preview

### Option 1: Live Local Server (Recommended)
Run the included native server script:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
The server will start at **http://localhost:8080** and launch in your default web browser.

### Option 2: Direct File Opening
Navigate to the directory and double-click `index.html` or run:
```powershell
Start-Process "C:\Users\ASUS\.gemini\antigravity\scratch\portfolio-website\index.html"
```

## 🚢 Publishing to the Web

Since this platform is completely static, you can deploy it for free in seconds:
- **Vercel**: Connect your GitHub repository or drag-and-drop the directory.
- **GitHub Pages**: Push this directory to GitHub and enable Pages in repository settings.
- **Netlify**: Drag and drop the folder directly onto `app.netlify.com/drop`.
- **Custom Domain**: Connect your domain (e.g., `delconjee.com`).
